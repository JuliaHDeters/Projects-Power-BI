# Dashboards de Mercado de Dados com Power BI

Este repositório reúne projetos desenvolvidos em Power BI com foco na análise do mercado de trabalho na área de dados. Utilizando um dataset real de vagas publicadas em 2024, os dashboards exploram informações como salários, cargos, habilidades mais demandadas e distribuição das oportunidades.

Os projetos fazem parte de um processo de aprendizado em Business Intelligence, análise de dados e visualização, aplicando conceitos como modelagem de dados, DAX, Power Query e design de dashboards.

## Projeto 1 — Dashboard de Mercado de Dados

![Projeto 1 (página 01)](/data-jobs-dashboard/images/Projeto%20Power%20BI%20-%20p.1.jpg)

O primeiro projeto apresenta um dashboard interativo com duas páginas, oferecendo uma visão geral do mercado de dados e uma análise detalhada por cargo.

Entre os principais recursos utilizados estão:

* KPIs com indicadores do mercado de trabalho
* gráficos de linhas, barras e dispersão para análise de tendências e salários
* matriz com formatação condicional e mini gráficos
* drill-through para explorar detalhes específicos de cada cargo
* segmentação de dados e navegação com bookmarks

O objetivo foi transformar dados de vagas em visualizações que permitam compreender tendências do mercado e apoiar profissionais interessados em ingressar ou evoluir na área de dados.

## Projeto 2 — Dashboard de Mercado de Dados 2.0

![![Darshboard 2.0](/data-jobs-dashboard/images/Projeto%20Power%20BI%20-%20versão%2002.jpg)

A segunda versão do projeto aprofunda a análise e aplica conceitos mais avançados de modelagem de dados, DAX e interatividade.

Diferente da primeira versão, o dashboard foi reorganizado em uma única página, reunindo os principais indicadores do mercado de dados em um painel mais compacto e focado.

Principais melhorias aplicadas:

* ETL e transformação de dados com Power Query
* modelagem de dados com relacionamentos entre tabelas
* medidas em DAX utilizando funções como CALCULATE, DIVIDE e MEDIAN
* uso de ALLSELECTED para cálculos percentuais dinâmicos
* parâmetro de campos permitindo alternar métricas nos gráficos

O resultado é um dashboard mais estruturado, interativo e voltado para explorar rapidamente tendências do mercado de trabalho em dados.

## Conclusão

Esses projetos demonstram a evolução no uso do Power BI para transformar dados de vagas em insights sobre o mercado de trabalho na área de dados.

Enquanto o primeiro dashboard foca na construção de visualizações e na experiência de navegação entre páginas, a segunda versão aprofunda aspectos técnicos como transformação de dados, modelagem e criação de métricas em DAX.

Juntos, os projetos mostram como técnicas de Business Intelligence podem ser utilizadas para organizar dados complexos e transformá-los em informações claras e úteis para análise de tendências do mercado.
